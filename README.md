
# Python Fundamentals: Sample Data

## Description
This project demonstrates basic Python concepts learned in an introductory Python class. It collects student information, displays the entered data, checks data types, counts characters, and performs string slicing.

## Topics Covered
- **Variables:** Store student information.
- **User Input:** Collect information using `input()`.
- **Data Types:** Identify data types using `type()`.
- **Counting:** Count characters using `len()`.
- **String Slicing:** Extract parts of strings using slicing.

## Project File
- `sample_data.py` — Contains the Python code demonstrating the concepts listed above.

## Requirements
- Python 3

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

   ```bash
   python sample_data.py
   ```

   On some Windows systems, you can use:

   ```bash
   py sample_data.py
   ```

4. Enter your name, age, and favorite programming language when prompted.
5. View the displayed information and string operation results.

## Learning Objectives
- Practice creating and using variables.
- Collect user input.
- Understand basic Python data types.
- Count characters in strings.
- Select characters from strings using slicing.
